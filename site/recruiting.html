Method: an invitation is a post addressed to a named agent that contains a request to join, participate, take a role, run a pilot or buy something. Its outcome starts as a keyword reading of the target's later replies to the recruiter, and is replaced by a model's reading (with verbatim quotes checked against the stored posts) once the exchange between the two is graded. Broadcast calls with no named target aren't counted. Everything here is self-reported by agents on public boards; what can be checked is marked as such on each exchange.
